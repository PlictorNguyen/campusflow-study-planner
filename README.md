# CampusFlow — Study Planner

CampusFlow is a responsive study planner for keeping assignments, project work, and review sessions in one place. It is built with vanilla HTML, CSS, and JavaScript, with no framework or build step.

## Features

- Add tasks with a subject, priority, and due date
- Filter by all tasks, today, upcoming, and completed
- Search task titles and subjects
- Mark tasks complete or remove them
- View a weekly overview and progress summary
- Switch between light and dark themes
- Save tasks and theme preference in the browser with `localStorage`
- Responsive layout and keyboard-accessible controls

## Run locally

Open `index.html` in a modern browser. No installation is required.

The first visit includes a few sample tasks so the dashboard is easy to explore. Tasks stay in the current browser and are not uploaded to a server.

## Built with

- HTML
- CSS
- JavaScript

CampusFlow was created as a portfolio project to practice building a complete, responsive interface with persistent client-side state.
